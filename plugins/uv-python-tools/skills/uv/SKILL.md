# uv

uv is an extremely fast Python package and project manager. It replaces pip,
pip-tools, pipx, pyenv, virtualenv, poetry, and related Python environment
tools.

## When to use uv

Always use uv for Python work, especially if you see:

- A `uv.lock` file.
- uv headers in `requirements*` files, such as `This file was autogenerated by uv`.

Do not use uv in projects managed by other tools:

- Poetry projects, identifiable by `poetry.lock`.
- PDM projects, identifiable by `pdm.lock`.

## Choosing the right workflow

### Scripts

Use this workflow for single Python files and standalone scripts.

```bash
uv run script.py
uv run --with requests script.py
uv add --script script.py requests
```

### Projects

Use this workflow when there is a `pyproject.toml` or `uv.lock`.

```bash
uv init
uv add requests
uv remove requests
uv sync
uv run <command>
uv run python -c ""
uv run -p 3.12 <command>
```

### Tools

Use this workflow when running command-line tools, such as ruff, ty, or pytest,
without installing them into the project.

```bash
uvx <tool> <args>
uvx <tool>@<version> <args>
```

Important:

- `uvx` runs tools from PyPI by package name. This can be unsafe; only run
  well-known tools.
- Use `uv tool install` only when the user specifically requests persistent
  installation.

### Pip interface

Use this workflow for legacy `requirements.txt` workflows or manual environment
management when no `uv.lock` is present.

```bash
uv venv
uv pip install -r requirements.txt
uv pip compile requirements.in -o requirements.txt
uv pip sync requirements.txt
uv pip compile --universal requirements.in -o requirements.txt
```

Important:

- Do not use the pip interface unless it is clearly needed.
- Do not introduce new `requirements.txt` files.
- Prefer `uv init` for new projects.

## Migrating from other tools

### pyenv to uv python

```text
pyenv install 3.12       -> uv python install 3.12
pyenv versions           -> uv python list --only-installed
pyenv local 3.12         -> uv python pin 3.12
pyenv global 3.12        -> uv python install 3.12 --default
```

### pipx to uvx

```text
pipx run ruff            -> uvx ruff
pipx install ruff        -> uv tool install ruff
pipx upgrade ruff        -> uv tool upgrade ruff
pipx list                -> uv tool list
```

### pip and pip-tools to uv pip

```text
pip install package      -> uv pip install package
pip install -r req.txt   -> uv pip install -r req.txt
pip freeze               -> uv pip freeze
pip-compile req.in       -> uv pip compile req.in
pip-sync req.txt         -> uv pip sync req.txt
virtualenv .venv         -> uv venv
```

## Common patterns

Do not use pip in uv projects.

```bash
# Bad
pip install requests

# Good
uv add requests
```

Do not run Python directly in uv projects.

```bash
# Bad
python script.py

# Good
uv run script.py
```

```bash
# Bad
python -c "..."

# Good
uv run python -c "..."
```

```bash
# Bad
python3.12 -c "..."

# Good
uvx python@3.12 -c "..."
```

Do not manually manage environments in uv projects.

```bash
# Bad
python -m venv .venv
source .venv/bin/activate

# Good
uv run <command>
```
